# Saved comparison results

These summaries, benchmark measurements and environment records come from the
original experiments. Use them to compare a reproduced run. The simulation and
analysis never read this folder as new experimental output; new runs write to
`data/`, `analysis/`, `results/` and `logs/`.

`number_sources.json` links the original formatted values to analysis keys.
New timing measurements can differ. `validation.json` records the executed
checks; the verification procedure is described in `docs/validation.md`.
