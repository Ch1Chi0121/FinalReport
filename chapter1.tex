\chapter{Introduction}\label{sec:intro}
One grain can settle on a stable sandpile or start a cascade of topplings, depending on the configuration it encounters. This variation makes the sandpile a useful model for studying how a fixed local rule produces responses over a wide range of sizes.

Bak, Tang, and Wiesenfeld introduced self-organized criticality (SOC) to describe systems that develop critical behaviour under slow driving, without an externally tuned critical parameter~\cite{bak1987,bak1988}. Their sandpile model combines gradual input with rapid redistribution and loss at the boundary.

We ask how the stationary configuration measure, the response to external driving and the grouping of events each affect avalanche statistics. For the two-dimensional BTW model, we first compare height, flux and avalanche distributions across lattice sizes. The Abelian property provides exact checks on stabilization and on the mean response to input.

Three controlled extensions isolate the roles of driving, geometry and event definition. We bias input towards the centre while keeping the graph fixed, replace the open square by a cylinder while retaining uniform input, and compare four-grain batches with the same grains added sequentially. All comparisons retain the threshold-four toppling rule. Matching the inputs in the batch comparison lets us distinguish changes caused by grouping from differences between random input sequences.
