\chapter{Introduction}\label{sec:intro}
Each input to the sandpile is just one grain, but its effect depends on the configuration it lands on. A stable site may absorb the grain, or a toppling may push neighbouring sites past their thresholds and start a cascade. This makes the model useful for studying a basic question in complex systems: how can the same small input produce responses of very different sizes?

Bak, Tang, and Wiesenfeld introduced self-organized criticality (SOC) to describe systems that develop critical behaviour under slow driving, without an externally tuned critical parameter~\cite{bak1987,bak1988}. Their sandpile model combines gradual input with rapid redistribution and loss at the boundary. Its simple rules allow us to examine how local instability affects the system as a whole.

We ask whether changes in avalanche statistics reflect a different stationary state, a different response to external driving, or simply a different grouping of avalanche events. Using the two-dimensional BTW model in the assignment~\cite{handout}, we examine relaxation, height, flux, distributions and correlations across lattice sizes. The Abelian property provides exact checks on the simulation.

Three controlled extensions separate these possible sources of change. Spatial bias changes where grains enter while preserving the stationary recurrent measure on the same graph. Cylindrical boundaries change connectivity and dissipation, potentially changing both stationary configurations and responses. Four-grain batches regroup a matched input stream; exact Abelian identities preserve sequential toppling totals, loss totals and final configurations. Each comparison changes one feature while retaining deterministic threshold-four toppling, so a change in event statistics can be interpreted in terms of its specific mechanism.
